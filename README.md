# 🎂 Birthday Wish - Create Your Own Birthday Website

A beautiful, animated 3-page birthday website. No coding knowledge required!

## ⚡ Quick Start (2 Minutes)

### Step 1: Download This Repository

**Option A: Clone with Git**
```bash
git clone https://github.com/YOUR-USERNAME/birthday-wish.git
cd birthday-wish
```

**Option B: Download as ZIP**
1. Click the green **Code** button on this page
2. Click **Download ZIP**
3. Extract the folder to your computer

### Step 2: Open the Website

1. Open the downloaded `birthday-wish` folder
2. Double-click **`birthday-wish.html`**
3. Your website opens in your browser

✅ **Done!** Your website is running on your computer.

## 🎨 Quick Customization

### Edit Text
1. Right-click `birthday-wish.html`
2. Open with **Notepad** (or any text editor)
3. Find and change the text you want
4. Save (**Ctrl+S**)
5. Refresh browser (**Ctrl+Shift+R**)

### Add Photos
1. Prepare 2-5 photos (JPG format)
2. Rename them: `page2pic1.jpg`, `page2pic2.jpg`, `page2pic3.jpg`, etc.
3. Put them in the same folder as `birthday-wish.html`
4. Refresh browser

### Add Video
1. Get a video file (MP4 format)
2. Rename it to: `video.mp4`
3. Put it in the same folder
4. Refresh browser

### Add Music
1. Get a music file (MP3 format)
2. Rename it to: `song.mp3`
3. Put it in the same folder
4. Refresh browser

## 📋 File Naming Rules

**IMPORTANT:** Names must be EXACT (lowercase, no spaces):
- `page2pic1.jpg` ✅ (not `Photo1.jpg`)
- `page2pic2.jpg` ✅ (not `photo 2.jpg`)
- `video.mp4` ✅ (not `Video.mp4`)
- `song.mp3` ✅ (not `Song.mp3`)

## 🚨 Quick Fixes

**Photos not showing?**
- Check filenames: `page2pic1.jpg`, `page2pic2.jpg`
- Files must be in same folder as HTML
- Hard refresh: **Ctrl+Shift+R**

**Video not playing?**
- Filename must be `video.mp4` (lowercase)
- File must be in same folder
- Hard refresh: **Ctrl+Shift+R**

**Changes not showing?**
- Save: **Ctrl+S**
- Hard refresh: **Ctrl+Shift+R**
